# v0.6 Polish and Open Source Ready

This milestone adds operational polish and repository readiness.

## What was added

- Optional UI/API auth token support (`UI_AUTH_TOKEN`)
  - Supported via query parameter `?token=...`
  - Or `Authorization: Bearer <token>` header
- Container setup:
  - `Dockerfile`
  - `docker-compose.yml`
- CI pipeline:
  - `.github/workflows/ci.yml`
  - Checks formatting, tests, and build
- Consolidated project usage docs:
  - `README.md`

## Behavior

- When `UI_AUTH_TOKEN` is empty, UI and API endpoints are open for local development
- When set, protected endpoints require token:
  - `/`
  - `/api/generate`
  - `/api/notes`
  - `/api/notes/:filename`
