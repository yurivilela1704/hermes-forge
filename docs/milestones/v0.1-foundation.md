# v0.1 Foundation

This milestone sets up the project base with a small HTTP server and configuration loading.

## What was added

- Go module (`go.mod`)
- Planned folder structure from `PLAN.md`
- Basic server entrypoint at `cmd/server/main.go`
- `.env.example` with all planned environment variables
- Prompt template placeholder in `templates/default.tmpl`
- Initial placeholder files for internal packages

## Server behavior

The server currently exposes:

- `GET /health` returns `{"status":"ok"}`

This endpoint is useful for local checks, Docker health checks, and CI smoke tests.

## Configuration loading approach

The app uses Go standard library only:

- Reads `.env` manually (if present)
- Ignores empty lines and comments (`# ...`)
- Supports quoted values (`"value"` or `'value'`)
- Does not overwrite variables already defined in the environment

This keeps behavior simple and explicit while avoiding external dependencies.

## Why this is useful for learning Go

- Shows `net/http` with `ServeMux`
- Shows small config helpers (`getEnv`, `loadConfig`)
- Shows explicit error handling and startup logging
- Shows how to parse text files with `bufio.Scanner`

## How to run

1. Copy `.env.example` to `.env`
2. Adjust values as needed
3. Run:

```bash
go run ./cmd/server
```

Then test:

```bash
curl http://localhost:8080/health
```

Expected response:

```json
{"status":"ok"}
```
