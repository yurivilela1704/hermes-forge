# v0.5 Web UI

This milestone adds a simple browser UI served by Go.

## What was added

- Static UI served from:
  - `web/index.html`
  - `web/static/style.css`
  - `web/static/app.js`
- Server routes:
  - `GET /` serves the UI
  - `POST /api/generate` for manual note generation
  - `GET /api/notes` to list generated notes
  - `GET /api/notes/:filename` to read note content

## UI capabilities

- Manual input form for title, author, repository, branch, description, commits
- Generate and save a note through `/api/generate`
- Preview generated note text in browser
- List saved notes and open each note content

## Notes

- UI remains plain HTML/CSS/JS with no frontend framework (as planned)
- Manual generation requires LLM provider config to be valid
