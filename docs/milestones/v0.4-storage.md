# v0.4 Storage

This milestone persists generated release notes on disk and exposes read/list APIs.

## What was added

- `internal/storage/storage.go`
  - `Store` for note file persistence in `OUTPUT_DIR`
  - Slugified filename generation with date prefix:
    - `YYYY-MM-DD_<branch-or-title>.md`
  - Collision handling by suffix (`-1`, `-2`, ...)
- `internal/storage/index.go`
  - `index.json` load/save helpers
  - Atomic index writes (`.tmp` + rename)
- Server integration in `cmd/server/main.go`
  - Initializes storage on startup
  - Saves generated notes after webhook-triggered generation
  - Adds API endpoints:
    - `GET /api/notes`
    - `GET /api/notes/:filename`

## API behavior

- `GET /api/notes`
  - Returns JSON array of note metadata from `index.json`
- `GET /api/notes/:filename`
  - Returns markdown content for a saved note
  - Returns `404` if note does not exist

## Data model

Index metadata contains:

- `filename`
- `provider`
- `repository`
- `title`
- `author`
- `branch`
- `number`
- `url`
- `created_at`

## Notes

- Generation still depends on LLM configuration from `v0.3`
- If LLM is not configured, webhook events are accepted but no files are generated
- Storage remains local filesystem only (as planned)
